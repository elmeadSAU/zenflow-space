# 🧘 ZenFlow Space

An elegant, ambient productivity dashboard built with Node.js, Express, and HTML5/CSS3. Containerized using Docker and integrated with Google Cloud Run service architecture blueprints.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend:** Node.js, Express Framework
* **DevOps:** Docker, Google Cloud Platform SDK

## 💻 Local Setup
1. Run `npm install` to sync local dependencies.
2. Run `npm start` to boot the development server.
3. Navigate to `http://localhost:8080` in your browser.
